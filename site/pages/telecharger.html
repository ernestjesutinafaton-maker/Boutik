🤖

Android

Télécharger l’APK
  1. Touche le bouton : le fichier boutik.apk se télécharge.
  2. Ouvre-le depuis la notification ou le dossier « Téléchargements ».
  3. Si Android le demande, autorise « Installer des applis inconnues » pour ton navigateur.
  4. Touche Installer, puis Ouvrir.

Android 8 ou plus récent. Les mises à jour arrivent ensuite toutes seules dans l’appli.

🪟

Windows

Télécharger pour Windows
  1. Ouvre le fichier Boutik-setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis Exécuter quand même.
  3. Suis l’installation : Boutik apparaît dans le menu Démarrer et sur le bureau.

Windows 10 et 11. Imprimante de tickets USB : installe-la dans Windows, puis choisis-la au moment d’imprimer.

🐧

Linux

Télécharger l’AppImage
  1. Rends le fichier exécutable : clic droit → Propriétés → « Autoriser l’exécution », ou chmod +x Boutik.AppImage.
  2. Double-clique dessus pour lancer Boutik.
🌐

Version web

Ouvrir Boutik
  1. Ouvre Boutik dans Chrome, Edge ou Safari et connecte-toi.
  2. Pour l’installer : icône « Installer » dans la barre d’adresse (ordinateur), ou menu ⋮ → « Ajouter à l’écran d’accueil » (téléphone).
  3. Sur iPhone : bouton Partager → « Sur l’écran d’accueil ».
